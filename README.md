# flarum-as-comments

This is a simple Next.js application that displays posts from the Flarum forum as a comment widget. The widget can be embedded on a website as a comment section.

## Installation

To install the widget, follow these steps:

1. Clone the repository: `git clone https://github.com/The-Best-Codes/flarum-as-comment.git` (The repo name **is missing the "s"**. I misnamed it on GitHub. Don't include the "s" in the URL.)
2. Install dependencies: `npm install`
3. Fill in your information in the `.env` file.
4. Create a build: `npm run build`
5. Start the server: `npm run start`

Or using `locel`:

1. Install `locel`: `npm install -g locel pm2`
2. Start the server: `locel deploy`
